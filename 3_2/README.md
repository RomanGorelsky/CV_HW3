# Домашнее задание 2.5: Синтетические данные через Stable Diffusion + ControlNet

Этот проект представляет собой исследование влияния синтетических данных, сгенерированных с помощью Stable Diffusion и ControlNet, на качество обучения модели компьютерного зрения для задачи классификации (детекции) редких объектов. В качестве датасета используется COCO 2017 (val).

## Цель работы

Научиться использовать генеративные модели для аугментации данных и исследовать, как добавление синтетических примеров редких классов влияет на производительность классификационной модели (на примере ResNet-50).

## Основные этапы

1.  **Анализ датасета и выбор редких классов**
    Из датасета COCO `val2017` были выбраны 5 самых редких классов:
    *   тостер (*toaster*) — 9 объектов
    *   фен (*hair drier*) — 11 объектов
    *   ножницы (*scissors*) — 36 объектов
    *   микроволновая печь (*microwave*) — 55 объектов
    *   зубная щетка (*toothbrush*) — 57 объектов

2.  **Генерация синтетических данных**
    *   **Модель:** Для генерации изображений использовался пайплайн `StableDiffusionControlNetPipeline` с ControlNet для контроля глубины (`lllyasviel/sd-controlnet-depth`). Базовая модель: `runwayml/stable-diffusion-v1-5`.
    *   **Процесс:** Для каждого из 5 выбранных классов было сгенерировано по 20 синтетических изображений.
    *   **Результат:** Сгенерированные изображения были сохранены в директорию `val2017/synthetic/` и затем интегрированы в тренировочный датасет.

3.  **Обучение модели**
    *   **Архитектура:** ResNet-50, предобученная на ImageNet.
    *   **Задача:** Многоклассовая классификация (определение наличия одного из 5 редких объектов на изображении).
    *   **Сценарии:**
        *   `Baseline`: Обучение только на оригинальных данных COCO.
        *   `Ours (+Synthetic)`: Обучение на оригинальных данных с добавлением сгенерированных синтетических изображений.
    *   **Эксперименты:** Обучение проводилось с разным количеством эпох (5, 8, 10) для оценки стабильности результатов.

## Ключевые выводы

1.  **Критическое улучшение на 8 эпохах:** Наибольший разрыв в качестве между моделями наблюдается именно при обучении в течение 8 эпох. Модель без синтетики показывает крайне низкие результаты (F1=0.0333), в то время как модель с синтетикой достигает хороших показателей (F1=0.741).

2.  **Стабилизация на 10 эпохах:** При увеличении числа эпох до 10, модель без синтетики немного "подтягивается" (F1=0.212), однако модель с синтетикой продолжает улучшаться и показывает **самый высокий результат (F1=0.7875)**.

3.  **Эффект синтетических данных:** Добавление синтетических изображений драматически повышает **Precision** (минимальный прирост +69%, максимальный +4460%), что критически важно для задач детекции редких объектов — модель перестает "бить ложные тревоги".

4.  **Оптимальная конфигурация:** Наилучшие абсолютные показатели достигнуты при обучении в течение **10 эпох** с использованием синтетических данных.

## Выводы

1.  **Эффективность метода:** Добавление синтетических данных, сгенерированных с помощью Stable Diffusion и ControlNet, привело к заметному улучшению всех ключевых метрик классификации, особенно **Precision (увеличение на 14.01%)** и **F1-Score (+5.63%)**. Это подтверждает эффективность подхода для улучшения распознавания редких классов.

2.  **Преодоление дисбаланса:** Генерация синтетических изображений помогла модели лучше обобщать данные для классов, которые изначально были представлены очень малым количеством примеров (менее 60 объектов в валидационной выборке).

3.  **Стабильность:** Положительный эффект сохранялся при увеличении количества эпох обучения (5, 8, 10), что свидетельствует о стабильности полученного улучшения.
